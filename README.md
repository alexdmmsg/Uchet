# Копилка — PWA

Учёт доходов и расходов. Работает без интернета, ставится на экран телефона как приложение.
Данные хранятся только на телефоне (в памяти браузера). Раз в месяц делайте «Резервную копию».

## Как опубликовать (бесплатно, GitHub Pages)
1. Создайте на github.com новый публичный репозиторий, например `Uchet`.
2. «Add file → Upload files» — перетащите все файлы из этой папки, нажмите «Commit».
3. Settings → Pages → Source: «Deploy from a branch», Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты приложение будет по адресу `https://alexdmmsg.github.io/Uchet/`.

## Как установить на телефон
- Android (Chrome): откройте адрес → меню ⋮ → «Добавить на главный экран» / «Установить приложение».
- iPhone (Safari): откройте адрес → «Поделиться» → «На экран „Домой“».

## Обновление
Замените файлы в репозитории и увеличьте номер версии в `sw.js` (`kopilka-v1` → `kopilka-v2`).
